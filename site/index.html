Engineering Notes

How an Artefact Gets Made, and Why the Design Argues Back

Those Who Came Before is a game about an archaeologist whose mistakes compound into an unreliable narrative. These pages document two things: the generation pipeline that makes every artefact a real object with a structure, materials and a ground truth the player never reads directly; and the design that turns misreading it into the point.

Written for developers who build software but haven't built procedural generation. No prior archaeology required; no prior game development either.
